# 🗂️ TEMPO V4 — بوت TempVoice بلوحة تحكم عربية

بوت ديسكورد لإنشاء روم صوتية خاصة عند الدخول إلى **➕・إنشاء روم**. ينشئ رومًا مؤقتة، وينقل العضو إليها، ويعرض لوحة تحكم مطابقة تقريبًا للصورة المرجعية: **صورة لوحة بالعنوان الأصلي Temp Voice Panel** وأسماء الأوامر بالعربي فوق **15 زرًا فعليًا قابلاً للنقر (3 صفوف × 5)** داخل شات الروم الصوتي.

**متطلبات التشغيل:** Node.js 22.12+؛ لا يحتاج FFmpeg أو yt-dlp.

## الأزرار الـ15

| الصف الأول | الصف الثاني | الصف الثالث |
| --- | --- | --- |
| 🪧 تغيير الاسم (نافذة) | 🔇 قفل الروم | 🎙️ ميوت عضو (اختيار شخص) |
| 👥 تحديد عدد الأعضاء (0–99) | 🔊 فتح الروم | 🎤 فك الميوت |
| 🔨 طرد عضو من الروم | 🙈 إخفاء الروم | 🚫 منع عضو من الروم |
| 👑 نقل الملكية لعضو موجود | 👁️ إظهار الروم | ✅ السماح لعضو بالدخول |
| 🗑️ حذف الروم مع تأكيد | 🌍 اختيار الريجن | 🔗 دعوة عضو بالخاص |

جميع الأزرار قابلة للضغط. أزرار اختيار الأشخاص تظهر قائمة Discord؛ الاسم والعدد يظهران نافذة كتابة؛ وتغيير الريجن قائمة مناطق. يستطيع **مالك الروم** أو مشرف يمتلك `Manage Channels` استخدام الأزرار. عند خروج المالك مع بقاء أعضاء آخرين، يمكن لأحد الموجودين استخدام `/claim` لاستلام الروم. عند خروج آخر عضو بشري تُحذف الروم بعد مهلة افتراضيًا 15 ثانية. وهناك فحص احتياطي كل 30 ثانية للرومات الفارغة إذا لم يصل حدث المغادرة.

الميوت هو **كتم سيرفر**؛ يحتاج البوت إلى `Mute Members`، ويزيل البوت الكتم الذي فعّله مالك الروم عندما يغادر العضو. السماح/المنع يحددان أذونات الروم فقط. صلاحية Administrator والأذونات الخاصة قد تتجاوز قفل الروم أو إخفاءها. الدعوة ترسل رسالة خاصة للعضو (قد تفشل إذا أغلق رسائله الخاصة) وتسمح له بدخول الروم.

## الصلاحيات: من يستطيع استخدام /setup؟

فقط **مالك السيرفر** أو صاحب صلاحية **Manage Server / ManageGuild** (بما في ذلك Administrator) يستطيع تشغيل `/setup`؛ الأعضاء العاديون لا يستطيعون. البوت نفسه يحتاج `Manage Channels`, `Manage Roles`, `Move Members` لنجاح إنشاء الروم، بالإضافة إلى بقية الصلاحيات المذكورة أدناه. أمر `/tempvoice disable` أيضًا يتطلب Manage Server.

## إصلاحات V4 مقارنةً بـ V3

- لوحة واحدة لكل روم: قفل إرسال تحديثات اللوحة لتجنب رسالتين متزامنتين؛ عند التشغيل/التحديث يبحث البوت عن اللوحات المكررة القديمة (آخر 100 رسالة) ويزيل الزائد منها ويحتفظ بالأصل.
- تنظيف موثوق للرومات: يعتمد على حالات الاتصال الصوتية بدل القائمة المعروضة للأعضاء، ويتجاهل بوتات الموسيقى عند حساب وجود أعضاء بشر، ويفحص الرومات تلقائيًا كل 30 ثانية عند ضياع حدث الخروج.
- 15 أيقونة PNG جديدة متساوية الحجم (128×128) ومحاذاة بوسط الأزرار، وتم تحديث الصورة العلوية أيضًا. يستخدم أسماء إيموجي `tempo_v4_XX` حتى لا يستعمل أيقونات V3 القديمة المخزّنة في تطبيق البوت.
- لا تشغّل نسختين من نفس البوت معًا ولا تستخدم نفس بيانات الرومات في عمليتي Node.js منفصلتين.

## رفعه إلى GitHub وتشغيله على Bot-Hosting.net

1. أنشئ تطبيق بوت جديد من https://discord.com/developers/applications واحصل على **التوكن**؛ لا تشاركه مع أحد ولا تضعه في GitHub.
2. عند دعوة البوت إلى السيرفر اختر نطاقي `bot` و `applications.commands`. الصلاحيات المطلوبة: `View Channels`, `Manage Channels`, `Manage Roles`, `Move Members`, `Mute Members`, `Connect`, `Send Messages`, `Attach Files`, `Embed Links`, `Read Message History`.
3. فك ضغط المشروع وارفع **محتويات المجلد** إلى GitHub: `src/`, `assets/`, `package.json`, `Dockerfile`, `README.md` وغيرها. **لا ترفع** `.env` أو `data/` أو `node_modules/`.
4. ارفع الملفات إلى Bot-Hosting عن طريق مدير الملفات أو استيراد المستودع من GitHub. تأكد أن `package.json` بجانب مجلد `src`.
5. في **Startup** ضع Entry File / `STARTUP_FILE` كالتالي: `src/index.js`. إذا أمكن تعيين Start Command: `npm start`.
6. في **Environment Variables** أضف `DISCORD_TOKEN` كمتغير سري. لإظهار الأوامر فورًا في سيرفر واحد يمكن إضافة `GUILD_ID` (رقم سيرفرك). لا تضع التوكن في الكود.
7. شغّل `npm install` مرة واحدة (أو فعّل تثبيت الحزم التلقائي في الاستضافة). ثم شغّل البوت.
8. داخل ديسكورد نفذ `/setup` كمسؤول، ثم ادخل **➕・إنشاء روم**. افتح **شات الروم الصوتي** وستجد اللوحة العربية. إذا لم تظهر استخدم `/panel` من أي شات نصي بينما أنت داخل الروم.

يمكن توصيل روم إنشاء وتصنيف موجودين عبر `/setup hub:<الروم> category:<التصنيف>`. أوامر أخرى: `/tempvoice status`، `/tempvoice disable`، `/panel`، `/claim`.

### استبدال النسخة القديمة

أوقف البوت، ثم ارفع ملفات المشروع الجديد مكان القديم **مع الاحتفاظ بمجلد `data/`** إن أردت الحفاظ على الملكيات والإعدادات المحفوظة. استبدل ملفات **`src/`** بالكامل وارفع مجلد **`assets/`** الجديد بكل الصور؛ بدونه لن تظهر اللوحة الجديدة. نفّذ `npm install`، ثم أعد التشغيل. ستُحدَّث لوحة الروم المحفوظة تلقائيًا إذا كانت لدى البوت صلاحية تعديلها. سيحاول V4 حذف الرسالة الثانية القديمة إن وُجدت مع الاحتفاظ بلوحة واحدة.

### ملاحظات الاستضافة

- لحفظ إعدادات السيرفر وملكية الرومات بعد إعادة تشغيل البوت: اجعل `DATA_DIR` مجلدًا دائمًا قابلًا للكتابة مثل `/home/container/data`.
- بدون توفير استضافة مستمرة، لن ينشئ البوت رومات أثناء انقطاعه.
- البوت مخصص لعملية Node.js واحدة؛ لا تشغّل نسختين بنفس ملف البيانات.
- **التصميم العلوي صورة PNG ثابتة** تحاكي شكل البطاقة الأصلية؛ **الأزرار الخمسة عشر تحتها مكونات Discord حقيقية قابلة للنقر** وليست صورة. لا تظهر الإحصاءات الديناميكية في البطاقة حتى تحافظ على الشكل المرجعي.
- يحاول البوت عند تشغيله تحميل الـ15 أيقونة كتعبيرات Emoji خاصة بتطبيق البوت؛ إذا رفض Discord هذه الخطوة يستخدم إيموجيات قياسية بديلة، وتظل الأزرار تعمل. لتعطيل رفع الإيموجي أضف `TEMPO_CUSTOM_EMOJIS=false` إلى متغيرات البيئة. قد تختلف هيئة أزرار Discord قليلًا حسب التطبيق أو نظام التشغيل.
- يحتاج البوت **Attach Files** لنشر البطاقة المصورة داخل شات الروم الصوتي.
- إذا واجهت `Cannot find module /home/container/index.js` غيّر ملف بدء التشغيل إلى `src/index.js`.
- إذا لم تنجح أوامر كتم العضو: امنح البوت `Mute Members` وتأكد أن رتبته وصلاحياته مناسبة.

```bash
npm start
npm run check
npm test
```

### درجة الاختبار

نجحت فحوصات تركيب JavaScript وستة اختبارات محلية (من ضمنها اختيار رسالة لوحة واحدة واكتشاف الروم الفارغة). تشغيله الفعلي داخل سيرفر ديسكورد والتفاعل مع واجهة API يتطلب اختبارًا على حسابك واستضافتك؛ لم يُجرَ هذا الاختبار هنا.
